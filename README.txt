GYM WALTER - PWA

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio nuevo en GitHub.
2. Sube TODOS los archivos de este ZIP a la raiz del repositorio.
3. Abre Settings > Pages.
4. En Build and deployment elige Deploy from a branch.
5. Selecciona la rama main y la carpeta / (root), y guarda.
6. Abre la direccion HTTPS que GitHub Pages muestre.

INSTALAR EN IPHONE
1. Abre la direccion publicada usando Safari.
2. Pulsa Compartir.
3. Pulsa Anadir a pantalla de inicio.
4. Activa Abrir como app web si aparece y pulsa Anadir.

NOTA: Los datos se guardan localmente en el navegador del dispositivo.
